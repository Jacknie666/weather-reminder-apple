# 🍎 Weather Reminder (Apple Style)

> **底层逻辑**：结合 Apple 设计美学与 DeepSeek AI 推理能力。实现从天气预警到学术干货的全自动化推送，构建高品质的生活效率闭环。

---

## 🚀 核心抓手 (Highlights)
*   **设计美学**：适配 Apple 风格的 HTML 邮件模板，极致视觉体验。
*   **AI 赋能**：利用 DeepSeek 模型生成每日学术提醒与穿衣建议。
*   **多时段推送**：支持每日 20:00 的次日预警，实现信息提前触达。
*   **云端闭环**：基于 GitHub Actions 零成本调度。

## 🛠 技术实现
1.  **Weather API**: 抓取实时天气与预报数据。
2.  **DeepSeek API**: 根据天气与用户目标生成定制化 Prompt。
3.  **GitHub Actions**: Cron 触发定时任务。
